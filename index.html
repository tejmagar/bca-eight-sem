Adding a subject later

Three steps

  1. Make a new folder beside or, for example dbms, and put that subject's index.html and its note PDFs inside it.
  2. Copy the marked subject card in this file, the block between the two comment lines, and paste it inside <div class="grid">.
  3. Change the href, the heading, the description and the list items. Delete the Coming later card once there is nothing left to add.
Everything here is static HTML, so it works from a local folder and from GitHub Pages with no build step.
