Q 1

What is Operational Research? Explain the general methods for solving OR models.

[1 + 4]  ·  Unit 1  ·  asked in 2021 and 2023

Definition

Operations Research (OR) is a scientific and systematic method of solving complex decision making problems. It uses mathematical models, statistical analysis and computational techniques to optimise a process and help an organisation take better decisions. Its main goal is to find the best possible solution for allocation of limited resources (time, money, material, labour) under given constraints.

Example: a company that wants to deliver goods at the least shipping cost models the situation as a transportation problem and solves it to get the cheapest routes.

General methods for solving OR models

The methods fall into three broad classes.

  1. Analytical methods. They use exact mathematical techniques such as calculus, algebra and linear programming to obtain a precise closed form solution. They apply when the model can be written as a set of equations or inequalities with known properties. Example: differentiating a cost function to find its minimum, or the EOQ formula in inventory control.
  2. Iterative (numerical) methods. Used when an analytical solution is difficult or impossible. The method starts from an initial feasible solution and improves it step by step until the optimal solution is reached. Example: the Simplex method for LPP, the MODI method in transportation, the Hungarian method in assignment.
  3. Simulation methods (Monte Carlo). Used for complex systems that contain probabilistic elements. Random numbers are generated to represent the uncertain variables, the system is run many times, and the results are analysed to estimate performance measures. Example: simulating a hospital emergency room or traffic flow.
Remember: analytical gives an exact answer, iterative improves a solution step by step, simulation imitates the system when maths alone cannot describe it.

Meaning of mathematical formulation

Mathematical formulation of an LPP means translating a real life business situation into a mathematical model made of four parts:

  1. Decision variables: the unknown quantities to be determined.
  2. Objective function: a linear expression to be maximised or minimised.
  3. Constraints: linear inequalities or equations expressing resource limits and requirements.
  4. Non negativity restrictions: the variables cannot take negative values.

Q 4

Write an algorithm to maximize the solution of an LPP using the Simplex method.

[5]  ·  Unit 2  ·  asked in 2021

Algorithm

  1. Convert the LPP into standard form. Add a slack variable to every ≤ constraint to turn it into an equation, and give each slack a zero coefficient in the objective function. All right hand side constants must be non negative and all variables non negative.
    x + y ≤ 10 → x + y + s₁ = 10 Max Z = c₁x₁ + c₂x₂ + 0·s₁ + 0·s₂
  2. Set up the initial simplex tableau. Rows are the constraints, columns are the decision variables, slack variables and the RHS column b. The slack variables form the initial basis, so the initial basic feasible solution is x = 0 and s = b.
  3. Test for optimality. Compute Zj = Σ CB × (column entries) and the net evaluation row Zj - Cj. If every Zj - Cj ≥ 0, the present solution is optimal, stop. Otherwise go to step 4.
  4. Select the pivot column (entering variable). Choose the column with the most negative Zj - Cj. That variable enters the basis.
  5. Select the pivot row (leaving variable). For each row compute the ratio b / (pivot column coefficient), ignoring zero and negative denominators. The row with the smallest non negative ratio is the pivot row and its basic variable leaves.
  6. Perform the pivot operation. The element at the intersection is the pivot (key) element. Divide the whole pivot row by the pivot element so that it becomes 1, then use row operations to make every other entry of the pivot column zero.
  7. Update the tableau. Replace the leaving variable by the entering variable in the basis column and write the new coefficients.
  8. Repeat steps 3 to 7 until all Zj - Cj ≥ 0. The final tableau gives the optimal values of the basic variables and Max Z.
Special cases worth one line each: if a pivot column has no positive coefficient the solution is unbounded; if some non basic variable has Zj - Cj = 0 in the final table there are multiple optimal solutions; a tie in the minimum ratio is degeneracy and is broken arbitrarily.
Q 5

Write an algorithm to minimize the solution of an LPP using the Simplex method.

[5]  ·  Unit 2  ·  asked in 2023

A minimization LPP is solved by the same simplex machinery. There are two accepted routes.

Route 1: convert to maximization (most common)

Min Z = Max (-Z)

Multiply the objective function by -1, solve exactly by the eight steps of the maximization algorithm, and at the end put Min Z = -(Max Z′).

Route 2: solve directly, with the optimality test reversed

  1. Convert every constraint into an equation. A ≤ constraint gets a slack variable, a ≥ constraint gets a surplus variable subtracted plus an artificial variable added, an = constraint gets only an artificial variable.
    x + y ≥ 5 → x + y - S₁ + A₁ = 5
  2. Penalise the artificial variables in the objective function. For a minimization problem use +M · A, where M is a very large positive number (Big M method). Alternatively use the Two Phase method: Phase 1 minimises the sum of the artificial variables to reach feasibility, Phase 2 optimises the original objective.
  3. Build the initial tableau with the artificial and slack variables in the basis.
  4. Compute Zj and the net evaluation row Cj - Zj.
  5. Optimality test for minimization: the solution is optimal when all Cj - Zj ≥ 0 (equivalently all Zj - Cj ≤ 0). Otherwise continue.
  6. Entering variable = the column with the most negative Cj - Zj. Leaving variable = the row with the minimum positive ratio b / (pivot column coefficient).
  7. Pivot: divide the pivot row by the key element, then clear the rest of the pivot column with row operations. Once an artificial variable leaves the basis its column may be deleted.
  8. Repeat until the optimality test is satisfied.
  9. Feasibility check: if any artificial variable is still in the final basis with a positive value, the problem has no feasible solution.
One line to remember: maximization stops when all Zj - Cj ≥ 0, minimization stops when all Cj - Zj ≥ 0. Everything else in the procedure is identical.

Q 7

Write the meaning of duality. What are the major steps of formulating dual LPPs? Justify with an example.

[5]  ·  Unit 2  ·  asked in 2024

Meaning of duality

Every linear programming problem has a second LPP associated with it. The original problem is called the primal and the associated one is called its dual. Duality states that the two problems are two views of the same situation: if the primal maximises profit from activities, the dual minimises the imputed value of the resources used by those activities.

Duality theorem: if the primal problem has an optimal solution then its dual also has an optimal solution, and the two optimal objective values are equal.

Primal to dual relationship

  • The dual of the dual is the primal.
  • Number of dual variables = number of primal constraints, and number of dual constraints = number of primal variables.
  • Max in the primal becomes Min in the dual and the inequality signs reverse.
  • The objective coefficients of the primal become the RHS constants of the dual, and the RHS constants of the primal become the objective coefficients of the dual.
  • The rows of the primal become the columns of the dual (the constraint matrix is transposed).

Major steps of formulating the dual

  1. Write the primal in standard (canonical) form: all constraints ≤ for a maximization primal, all constraints ≥ for a minimization primal, all variables non negative.
  2. Assign one dual variable y₁, y₂, ... ym to each primal constraint.
  3. Form the dual objective function using the primal RHS values as coefficients, and reverse the sense (Max becomes Min).
  4. Form one dual constraint for each primal variable, using the transposed coefficient column, with the inequality reversed, and the primal objective coefficient as the RHS.
  5. Add the sign restrictions. Dual variables are ≥ 0. If a primal variable is unrestricted its dual constraint becomes an equality.

Example

PRIMAL Max Z = x₁ - x₂ + 3x₃ subject to x₁ + x₂ + x₃ ≤ 10 2x₁ - x₂ - x₃ ≤ 2 2x₁ - 2x₂ - 3x₃ ≤ 6 x₁, x₂, x₃ ≥ 0

There are 3 variables and 3 constraints, so the dual has 3 constraints and 3 variables y₁, y₂, y₃. The objective is maximizing, so the dual minimises.

DUAL Min W = 10y₁ + 2y₂ + 6y₃ subject to y₁ + 2y₂ + 2y₃ ≥ 1 y₁ - y₂ - 2y₃ ≥ -1 y₁ - y₂ - 3y₃ ≥ 3 y₁, y₂, y₃ ≥ 0

Advantages of duality

  • The dual is often smaller and quicker to solve than the primal (m constraints become m variables).
  • Solving one problem gives the optimal solution of both.
  • The dual variables are shadow prices, the marginal worth of one more unit of each resource, which is used in sensitivity analysis.
  • It provides bounds on the primal optimum and a clear economic interpretation of the constraints.

Q 9

Write the Hungarian algorithm to solve the assignment problem.

[5]  ·  Unit 3  ·  asked in 2021 and 2023

What the assignment problem is

An assignment problem is a special transportation problem in which the number of sources equals the number of destinations and every supply and demand is 1. Each worker is given exactly one job and each job goes to exactly one worker, so as to minimise total cost or time.

Hungarian algorithm

  1. Check balance. If the number of rows is not equal to the number of columns, add a dummy row or dummy column with all costs zero to make the matrix square.
  2. Row reduction. Find the smallest element in each row and subtract it from every element of that row.
  3. Column reduction. In the resulting matrix find the smallest element in each column and subtract it from every element of that column. Every row and every column now has at least one zero.
  4. Make assignments and cover all zeros with the minimum number of lines.
    • Examine the rows one by one. If a row has exactly one zero, box that zero (assignment) and draw a vertical line through its column. If a row has more than one zero, skip it for now.
    • Repeat the same scan for the columns, drawing a horizontal line through the row of each single boxed zero.
    • Continue until every zero is either boxed or covered by a line.
  5. Optimality test. If the number of boxed assignments (lines) equals the number of rows or columns, the assignment is optimal. Stop.
  6. Revise the matrix if it is not optimal.
    • Find the smallest element that is not covered by any line.
    • Subtract it from every uncovered element.
    • Add it to every element that lies at the intersection of two lines (covered twice).
    • Leave the singly covered elements unchanged, then go back to step 4.
  7. Read the answer. Add the original costs of the boxed cells to get the minimum total cost.
Two variants to mention for extra marks: a maximization problem is converted to minimization by subtracting every element from the largest element of the matrix, and a restricted or infeasible assignment (a worker who cannot do a job) is handled by putting a very large cost M or ∞ in that cell so it never enters the solution.
Q 10

Classify the queueing models with examples.

[5]  ·  Unit 4  ·  asked in 2021

Queueing models are named with Kendall's notation (a / b / c) : (d / e) where a is the arrival distribution, b the service distribution, c the number of servers, d the system capacity and e the queue discipline. The four standard classroom models are:

A. Single server models

Model I: (M / M / 1) : (∞ / FCFS)

  • Poisson arrivals, exponential service time, one server, infinite waiting space, first come first served.
  • Customers never leave the queue and the system is stable only when ρ = λ / μ < 1.
  • Example: a single ATM in a 24 hour bank lobby. Customers arrive at random, transaction times vary, nobody is turned away and they are served in order of arrival.

Model II: (M / M / 1) : (N / FCFS)

  • Same as Model I but the system holds at most N customers including the one in service. A customer who arrives when the system is full is turned away.
  • It works even when ρ ≥ 1 because the finite capacity prevents an infinite queue.
  • Example: a small coffee shop with 5 seats, one person ordering and four waiting. New customers leave when all seats are full.

B. Multi server models

Model III: (M / M / S) : (∞ / FCFS)

  • Poisson arrivals, exponential service, S parallel servers, one common queue, infinite capacity.
  • Stable when ρ = λ / (Sμ) < 1.
  • Example: a bank with 4 tellers and a single common queue. The customer at the head goes to whichever teller falls free first.

Model IV: (M / M / S) : (N / FCFS)

  • S servers with a finite capacity of N customers, where N > S. S are in service and N - S wait. Arrivals are rejected when the system is full.
  • Example: a drive through with 2 service windows and room for 5 cars, so 2 are served and 3 wait. Further cars drive away.
M stands for Markovian, that is Poisson arrivals and exponential service. Other symbols are D for deterministic (constant) times, G for a general distribution and Ek for an Erlang-k distribution.

Given

(a) Proportion of time the shop is empty

P₀ = 1 - ρ = 1 - 5/6 = 1/6 = 0.1667 i.e. about 16.67 % of the time

The repairman is idle for roughly 10 minutes in every hour, and busy 83.33 % of the time.

(b) Average number of customers

In the system Ls = λ / (μ - λ) = 5 / (6 - 5) = 5 customers In the queue Lq = λ² / [μ(μ - λ)] = 25 / (6 × 1) = 4.17 customers Check: Lq = Ls - ρ = 5 - 0.8333 = 4.17 ✓

In the system Ws = 1 / (μ - λ) = 1 / 1 = 1 hour = 60 minutes In the queue Wq = λ / [μ(μ - λ)] = 5 / 6 hour = 50 minutes Check: Ws = Wq + 1/μ = 50 + 10 = 60 minutes ✓

(d) Probability of at least five customers in the shop

P(n ≥ k) = ρk P(n ≥ 5) = (5/6)⁵ = 3125 / 7776 = 0.4019 i.e. about 40.19 %
Summary: the shop is empty 16.67 % of the time, holds 5 customers on average with 4.17 waiting, a customer spends 60 minutes in the shop of which 50 minutes is pure waiting, and there is a 40.19 % chance of finding five or more customers present.

Q 16

Write short notes on (any two): (a) EOQ   (b) Kendall's notation for queueing models   (c) Duality theorem   (d) Degeneracy in a transportation problem

[2.5 + 2.5]  ·  Units 2, 3, 4, 5  ·  asked in 2021 and 2023

(a) EOQ, Economic Order Quantity

EOQ is that order size which minimises the total inventory cost, made up of ordering cost plus carrying cost. Ordering cost falls as the order size grows because fewer orders are placed, while carrying cost rises because more stock is held. The two curves cross at the quantity where total cost is least, and that quantity is the EOQ.

EOQ Q* = √(2 D C₀ / Ch) D = annual demand C₀ = ordering cost per order Ch = carrying cost per unit per year (often i × unit price) Number of orders per year = D / Q* Total cost at EOQ = D·C₀/Q* + Q*·Ch/2 (plus purchase cost D × price)

Assumptions: demand is known and uniform, replenishment is instantaneous, lead time is constant (taken as zero), the price is constant with no discounts, ordering and carrying costs are known and constant, and shortages are not allowed.

(b) Kendall's notation for queueing models

Kendall's notation is a shorthand that describes any queueing system in five symbols.

(a / b / c) : (d / e) a = arrival (inter arrival time) distribution b = service time distribution c = number of servers d = system capacity (maximum customers allowed) e = queue discipline
  • Symbols for a and b: M = Markovian (Poisson arrivals, exponential service), D = deterministic or constant, G = general distribution, GI = general independent arrivals, Ek = Erlang-k distribution.
  • Symbols for c: 1 = single server, S = multiple servers, ∞ = infinite servers.
  • Symbols for d: ∞ = unlimited waiting space, N = finite capacity of N customers.
  • Symbols for e: FCFS or FIFO = first come first served, LIFO = last in first out, SIRO = service in random order, priority based.

Example: (M / M / 1) : (∞ / FCFS) means Poisson arrivals, exponential service, one server, infinite queue and first come first served, which is the single ATM model.

(c) Duality theorem

Every LPP (the primal) has an associated LPP called its dual. The duality theorem states: if the primal problem has an optimal solution then its dual also has an optimal solution, and the two optimal objective values are equal.

  • The dual of the dual is the primal.
  • Max in the primal corresponds to Min in the dual, and the inequality signs reverse.
  • Number of dual variables = number of primal constraints, number of dual constraints = number of primal variables.
  • If one problem has an unbounded solution the other is infeasible.
  • The dual variables are the shadow prices, the marginal value of one extra unit of each resource, which is the basis of sensitivity analysis.

(d) Degeneracy in a transportation problem

A basic feasible solution of a transportation problem with m sources and n destinations must have exactly m + n - 1 occupied (allocated) cells. If the number of allocations is less than m + n - 1 the solution is called degenerate, and the MODI optimality test cannot be applied because the ui and vj values cannot all be determined.

Remedy: allocate a very small quantity ε (epsilon, taken as almost zero) to one of the unoccupied cells having the least cost, chosen so that it does not form a closed loop with the existing allocations. Repeat until there are m + n - 1 occupied cells, then carry out the MODI test as usual. At the end ε is treated as zero, so it does not change the total cost.

Degeneracy can appear at two stages: in the initial basic feasible solution (when a row and a column are satisfied at the same time by one allocation), and during an improvement step (when two cells tie for the minimum in the closed loop).

Q 17

Define the various costs related to inventory. Explain ABC analysis with a suitable example.

[10]  ·  Unit 5  ·  asked in 2021

Part 1: costs associated with inventory

Inventory means the resources or items kept for future use. Holding them costs money, and so does running out of them. Inventory control tries to balance four kinds of cost.

1. Ordering cost (setup cost). The cost incurred every time an order is placed, independent of the size of the order. It covers the paperwork of raising a purchase order, communication and processing charges, shipping and handling fees, and inspection of the goods on arrival. If a firm places 100 orders a year at Rs. 50 each, the ordering cost is 100 × 50 = Rs. 5,000. Frequent small orders push this cost up.

2. Carrying or holding cost. The cost of keeping the stock in store for a period. It covers warehouse rent and utilities, insurance and security, deterioration, obsolescence, pilferage and damage, and above all the interest on the capital tied up in unsold stock. It is usually quoted as a percentage of the unit price per year. Stock worth Rs. 1,00,000 with a carrying rate of 20 % costs Rs. 20,000 a year to hold. Holding cost rises directly with the order size.

3. Shortage or stockout cost. The penalty for not having an item when a customer asks for it. It includes the profit lost on the sale that did not happen, the cost of emergency or express purchasing, production stoppage in a factory, and the intangible loss of goodwill which can also cost future sales. If a retailer loses 50 phone sales worth Rs. 500 each, the immediate loss is Rs. 25,000, and the customer who went away twice may never come back.

4. Purchase cost. The actual price paid for the goods, that is quantity × unit price, plus taxes, duties and transport if they are included in the price. It becomes an active part of the decision when the supplier gives a quantity discount, because then buying more per order lowers the unit price and the EOQ has to be re tested against the discounted price.

Part 2: ABC analysis

ABC analysis is a method of classifying inventory items according to their annual consumption value, so that control effort is spent where the money actually is. It applies the Pareto principle (the 80 / 20 rule): roughly 80 % of the total inventory value comes from only about 20 % of the items.

ClassDescription% of items% of valueManagement focus
AHigh value, low quantity10 to 20 %70 to 80 %Tight control, frequent review, accurate records, small safety stock
BModerate value, moderate quantity20 to 30 %15 to 20 %Regular monitoring, normal ordering rules
CLow value, high quantity50 to 70 %5 to 10 %Minimum control, bulk ordering, large safety stock

Steps to carry out ABC analysis

  1. List every item with its annual usage in units and its cost per unit.
  2. Compute the annual consumption value = annual usage × unit cost, and the grand total.
  3. Express each item's value as a percentage of the grand total.
  4. Rank the items in descending order of that percentage.
  5. Compute the cumulative percentage down the ranked list.
  6. Classify: items making up the first roughly 70 to 80 % of cumulative value are A, the next roughly 15 to 20 % are B, and the rest are C.
  7. Plot the cumulative percentage against rank to get the ABC curve.

Advantages

  • Control effort and working capital are concentrated on the items that matter most.
  • Better forecasting and better supplier negotiation on class A items, where a small percentage saving is a large sum.
  • Lower storage cost and a healthier stock turnover ratio.
  • Fewer stockouts of critical items and a better service level for customers.

Limitations

  • It is static, and the classification goes stale when demand shifts, so it must be reviewed regularly.
  • It looks only at money value and ignores the strategic criticality of an item, its lead time and supplier reliability. A cheap C class screw can stop a whole assembly line.
  • Setting up and maintaining the classification is time consuming and is not economical for very small firms.
  • Strict adherence may lead to neglect of B and C items.

Part 1: theory of two person zero sum games

A game is a competitive situation in which two or more rational players choose strategies and each receives a payoff that depends on the choices of all of them. A two person zero sum game is the simplest and most studied case.

  • Two person: exactly two players take part, conventionally called A and B.
  • Zero sum: whatever one player gains, the other loses exactly the same amount, so payoff(A) + payoff(B) = 0. Their interests are completely opposed.

Simple example: if A gains +5 by a move then B must lose -5. Chess, heads up poker and a tug of war are everyday zero sum games. In business, two firms fighting over a fixed market share play a zero sum game, since a percentage won by one is lost by the other.

Key terms

  • Players: the decision makers, usually two in basic models.
  • Strategy: a complete plan of action. A pure strategy means the player always chooses the same course of action, a mixed strategy means choosing among courses of action with fixed probabilities.
  • Payoff matrix: a table whose entries are the gains of the maximizing player A (and therefore the losses of B).
  • Value of the game (V): the expected payoff when both players use their optimal strategies.
  • Saddle point: a cell where MaxiMin = MiniMax. If it exists, the game is solved by pure strategies and its entry is the value of the game.

Assumptions

  1. There is a finite number of players, each with a finite number of possible courses of action.
  2. Player A tries to maximise his gain, player B tries to minimise his loss.
  3. Both players decide independently and simultaneously, without communication, so neither knows the other's move in advance.
  4. Both players know the full payoff matrix.
  5. The outcome of the game is predetermined by the strategies chosen.

Maximin and Minimax principles

MaxiMin (player A) : take the minimum of each row, then the maximum of those minima. MiniMax (player B) : take the maximum of each column, then the minimum of those maxima. If MaxiMin = MiniMax, the game has a saddle point and pure strategies solve it. If MaxiMin ≠ MiniMax, mixed strategies are required.

Dominance : delete row i if row i ≤ row j (A wants bigger payoffs) delete column i if column i ≥ column j (B wants smaller payoffs) average dominance uses the average of two rows or two columns 2 × 2 game without a saddle point, matrix [ a b ; c d ] p = (d - c) / (a + d - b - c) probability of row 1 for A 1 - p = probability of row 2 q = (d - b) / (a + d - b - c) probability of column 1 for B 1 - q = probability of column 2 V = (a d - b c) / (a + d - b - c) Always check MaxiMin ≤ V ≤ MiniMax
